"# hospitaldash" 

## Email digest ("Munshot Brief")

Optional, additive scheduled email of sector movers + fresh BSE filings, in the
Munshot newspaper style. The dashboard works unchanged until it's configured.

- One-time setup: **[SETUP-DIGEST.md](./SETUP-DIGEST.md)**
- Preview the email locally: `npm run preview-email` → open `email-preview.html`
- Test the API handlers: `npm run digest:selftest`
